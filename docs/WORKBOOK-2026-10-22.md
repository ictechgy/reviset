# 스프레드시트 버전 비교 · 2026-10-22

네이티브 Mac 앱의 **스프레드시트 버전 비교** 창을 추가했다. XLSX·ODS·UTF-8 쉼표 CSV를 버전 순서대로 가져오고, 고정 보고서에서 특정 버전의 내용과 변경 이력을 조회한다. 기존 PPTX/PDF 창과 보관소를 공유하며 원본 SHA와 이전 보고서를 보존한다.

이 문서는076 기능 도입 당시의 고정 검증 기록이다. 현재 앱·ZIP과 이후 수정은 [후속 개선 기록](WORKBOOK-RECOVERY-2026-10-22.md)을 따른다.

당시 앱 `release/Docver-Sheets.app`, ZIP `release/Docver-0.5.0-workbook3-arm64.zip`. 실행 소스 076306a0fab6a941627063f3bcf53cc36cab60a5; 이후 README·품질 기록은 문서만 바뀐 커밋으로 구분한다. 당시 Mac의 비공개 패키지 범위는 `PRIVATE_PACKAGE_READY`다. 소스·원본·실행·리뷰 결합은 [검증 JSON](../.omx/artifacts/workbook-20261022/composite-qualification.json), [ZIP 검증](../release/validation-workbook3.json)에 기록한다.

## 사용

앱 실행 후 파일 메뉴 **스프레드시트 버전 비교…** 또는 `⌘⇧O`. **XLSX·ODS·CSV 가져오기**로 버전을 순서대로 선택하거나 **3버전 엑셀 데모**를 연다. 이전/이후 버전·시트·주소와 비교 방식을 선택한다. 행 이동은 양쪽의 실제 주소와 테두리로 표시하며 행 대응은 추정임을 밝힌다. 셀 근거에서 저장값·수식·저장 결과·숫자 형식·기본 서식·원문 위치와 이어 읽기를 확인한다. 원문 범위는 UTF-16의 끝을 포함하지 않는 범위다. 양쪽 원문의 페이지는 함께 이동하며 설명을 표시한다.

전체 이력은 중간 변경을 유지하고 구간 차이는 두 끝점의 순변경이다. 특정 버전의 셀·시트 내용과 검색은 변경 여부와 별도로 조회한다. 배포 기록은 고정 보고서에 붙이는 로컬 라벨·이유이며 외부 전송이나 편집자 인증이 아니다. AI·내보내기에서 고정 보고서 JSON/JSONL/Markdown과 프로젝트 범위의 읽기 전용 MCP 설정을 제공한다.

## 한계

합계50만 materialized셀/10만 변경/256MiB보고서/파일64MiB가 함께 적용된다. 수식은 실행하거나 재계산하지 않고 저장된 결과의 신선도는 모름으로 표시한다. 차트·피벗·매크로·고급/조건부 서식·외부 데이터·Excel의 완전한 화면 동일성은 지원하지 않으며 발견한 범위는 gap으로 남긴다. CSV는 문자열이고 형식 간 수식/날짜/서식 표현을 같은 의미로 단정하지 않는다. `.xls` 등 지원 목록 밖 파일은 가져오지 않는다. 세부 계약은 [SPREADSHEETS.md](SPREADSHEETS.md), AI조회는 [MCP.md](MCP.md)다.

Apple Silicon arm64/macOS14+를 대상으로 현재 Mac에서 확인한 ad-hoc 서명 비공개 패키지다. 다른 Mac·DeveloperID 공증·공개 배포 합격이 아니다. 과거 OCR 스트레스와 PowerPoint strict 참조의 미해결은 계속 OPEN이다. 이번 스프레드시트 기능으로 보편 판독 품질을 합격 처리하지 않는다. 원래 네 앱·네 ZIP과 HANDOFF.md·PLAN.md의42개 해시가 일치한다.
